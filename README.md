# Fiches de cours

Fiches de cours mises en page (réseau, Internet, premiers pas en cybersécurité), une page par leçon, avec schémas, photos du matériel et petites BD d'analogies. Intercalaire « À savoir par cœur » avec un mode révision qui cache les réponses.

**En ligne** : https://gameandasmr-lang.github.io/fiches-de-cours/

## Fichiers
- `index.html` : le classeur (généré, ne pas modifier ici).
- `images/` : photos (Wikimedia Commons, crédits sous chaque image) et illustrations générées par IA.

La source vit dans un autre dossier de travail ; ce dépôt est mis à jour par un script de déploiement qui reconstruit `index.html` et copie les images.
